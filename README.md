# Slang Half-Life — how long does a slang term live?

In January 2023, the Wiktionary entry for **rizz** was looked up almost 97,000
times. Three and a half years later it gets under 1,000 lookups a month. That's a
whole life cycle — rise, peak, fade — in one word.

This project measures that cycle for hundreds of slang terms and asks one
question: **is slang dying faster than it used to?**

*Work in progress.*

## Install

pip install -e .
